# Insurance Navigator Agent — Demo

Live chat UI for the [Insurance Navigator Agent](https://github.com/giacode17/cock), a hackathon submission
for the CockroachDB × AWS Hackathon. Talks to a Claude-powered agent running on AWS Lambda, backed by
CockroachDB Cloud (Managed MCP Server + Distributed Vector Indexing) and Amazon Bedrock embeddings.

Source code: https://github.com/giacode17/cock
